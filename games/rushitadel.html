3스테이지 × 3라운드를 치르며 경험치로 레벨업해 포탑을 변형하고, 스테이지마다 테마별 보스(4종)와 싸웁니다. 저장은 3슬롯입니다. 기본 조작은 WASD 이동, 마우스 조준, 좌클릭 공격, 우클릭 동력 공격입니다.

2내 역할: QA: TC 작성·테스트 수행 예정

TC 문서
  • 기준 커밋에 실제로 구현된 기능만 TC로 썼습니다. 기획서에만 있고 코드에서 꺼진 기능은 범위 밖으로 따로 적었습니다.
  • 각 TC에 사전 조건, 절차, 테스트 데이터, 기대 결과, 우선순위(P1~P3), 유형, 근거 파일 경로를 둡니다.
  • '결과' 열은 Pass / Fail / Block / N/A 목록과 실행일로 채우게 했습니다.
테스트 수행 예정
  • 실제 Windows 빌드로 손 테스트할 스모크 세트 21개(약 38분)를 한 판 순서로 묶었습니다.

RS-MOV-001
기능 P1		WASD 이동과 대각선 속도
사전: 새 게임으로 STAGE 1 · R1 전투 중		1. W, A, S, D를 각각 1초씩 누른다
2. W+D를 1초 누른다
3. 두 경우의 이동 거리를 비교한다
데이터: 기본 이동 2.5 × 전투 속도 1.7 = 4.25 유닛/초		누른 방향으로 이동하고, 대각선(W+D)도 한 방향 이동과 같은 속도(약 4.25 유닛/초)로 움직인다 (대각선이 빠르지 않음)
RS-ATK-005
경계값 P1		동력 부족 시 발사 불가 (경계 70)
사전: 새 게임으로 STAGE 1 · R1 전투 중		1. 우클릭으로 동력을 30으로 만든다
2. 곧바로 우클릭한다
3. 동력이 69일 때 우클릭한다
4. 동력이 70 이상이 되면 우클릭한다
데이터: 동력 30 / 69 / 70		30과 69에서는 발사·소모가 없다. 70 이상에서만 발사되고 동력이 70 줄어든다
RS-SAV-004
예외 P1		손상된 저장 파일
사전: 슬롯 1 정상 저장, 게임 종료 상태		1. slot1.json을 메모장으로 열어 payload 안의 숫자 하나를 바꿔 저장한다
2. 게임을 실행해 '저장 슬롯'을 연다
3. 슬롯 1 버튼을 본다
데이터: 체크섬 불일치		슬롯 1에 '불러올 수 없음 / 저장 파일 검증 실패. 원본을 보존했습니다.'가 보이고 '불러오기'가 비활성이다. 파일은 지워지지 않는다. 다른 정상 슬롯이 없으면 타이틀의 이어하기도 비활성
RS-BOS-001
기능 P1		테마별 보스와 HUD
사전: R3 정리 직후		1. 보스 이름·HP를 HUD 오른쪽 위에서 본다
데이터: 풀 평원 = 적월 나비, 불·용암 = 용광로 거신, 얼음 = 빙환 수호자, 물 / 물·전기 = 수압·전격 쌍성, STAGE 1 HP 6000		테마에 맞는 보스가 나오고 '이름 · 1단계 6000/6000 패턴 이름'과 HP 막대가 보인다
